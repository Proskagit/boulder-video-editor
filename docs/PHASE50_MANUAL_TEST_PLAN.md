## Часть A. Замечания проверки Phase 49 (D069 §1–§5)

| # | Действие | Ожидание |
|---|---|---|
| A1 | Импортировать 3 файла, 2 из них добавить на таймлайн. Выделить эти 2 в медиатеке, нажать ✕ в строке одного из них | Один вопрос про 2 файла и их клипы; после «Удалить» исчезают оба файла и их клипы; третий на месте |
| A2 | Ctrl+Z | Оба файла и их клипы вернулись одним шагом |
| A3 | Выделить 2 файла, правая кнопка на одном из них → «Удалить из проекта» | Как A1: удаляются оба |
| A4 | Выделить 2 файла, правая кнопка на третьем (невыделенном) → «Удалить из проекта» | Удаляется только третий |
| A5 | Выделить 2 файла в медиатеке, нажать Delete | Удаляются выделенные файлы (с вопросом, если есть клипы); клипы на таймлайне, выделенные до этого, не тронуты Delete медиатеки |
| A6 | Выделить клип на таймлайне, щёлкнуть по таймлайну, нажать Delete | Удаляется клип (как раньше) |
| A7 | Новый проект, «Настройки…» → холст 1080×1920, таймлайн пуст | В Preview «Таймлайн пуст» и подсказка переносятся по ширине вертикального кадра и не вылезают за него |
| A8 | Посмотреть на пустой таймлайн | Подсказка «Таймлайн пуст…» стоит по центру свободного места под дорожками, не на линии дорожки (если места нет — её не видно, дорожки не перекрыты) |
| A9 | «Сохранить как…» у нового проекта | Своё окно: «Имя проекта», «Папка» с «Изменить…»; ниже строка «Проект будет сохранён в: …» |
| A10 | Ввести имя уже существующего проекта в этой папке, «Сохранить» | Сразу вопрос «Заменить проект?»; «Отмена» — окно возвращается с введённым именем; «Заменить» — проект сохранён туда |
| A11 | Ввести пустое имя, имя с «:» или с точкой в конце, имя существующего файла | Кнопка «Сохранить» недоступна, причина красным под полями |
| A12 | «Изменить…» | Системный выбор папки; выбранная папка в поле |
| A13 | Посмотреть на стрелки числовых полей (Inspector: «Масштаб», «Непрозрачность»; «Настройки…») | Значки стрелок примерно в 1,5 раза меньше прежних и помещаются в свои кнопки |
| A14 | Тренировка импортирована; плейхед там, где в тренировке нет пульса; «Шаблон» → «Пульс» | Окно «Нет пульса» с «ОК»: «В тренировке нет пульса для этого места видео — плашка «Пульс» не добавлена»; плашки нет, Undo пуст |
| A15 | То же там, где пульс есть | Плашка добавлена, как раньше |
