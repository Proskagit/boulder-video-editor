| A9 | «Сохранить как…» у нового проекта | Своё окно: «Имя проекта», «Папка» с «Изменить…»; ниже строка «Проект будет сохранён в: …» |
| A10 | Ввести имя уже существующего проекта в этой папке, «Сохранить» | Сразу вопрос «Заменить проект?»; «Отмена» — окно возвращается с введённым именем; «Заменить» — проект сохранён туда |

| A14 | Тренировка импортирована; плейхед там, где в тренировке нет пульса; «Шаблон» → «Пульс» | Окно «Нет пульса» с «ОК»: «В тренировке нет пульса для этого места видео — плашка «Пульс» не добавлена»; плашки нет, Undo пуст |
| A15 | То же там, где пульс есть | Плашка добавлена, как раньше |

## Часть B1. Магнитная главная дорожка (D069 §6)

| # | Действие | Ожидание |
|---|---|---|
| M1 | Новый проект | Кнопка-магнит над таймлайном включена (подсказка «Магнит главной дорожки (N)»); клавиша N переключает её; привязка к краям работает всегда |
| M2 | Добавить на V1 три клипа A, B, C. Удалить B | C встаёт вплотную к A; Ctrl+Z возвращает B и C одним шагом |
| M3 | Перетащить файл из медиатеки в первую половину клипа B | Новый клип встаёт перед B, B и C сдвигаются вправо, пропусков нет |
| M4 | То же во вторую половину B | Новый клип встаёт после B |
| M5 | Перетащить A за конец C | Порядок B, C, A, первый клип с 0, без пропусков |
| M6 | Обрезать конец A (короче, потом длиннее) | Следующие клипы едут за краем A, ни пропуска, ни наложения |
| M7 | На V2 поставить текст над B, на A1 — музыку. Удалить A | Текст едет вместе с B; музыка на A1 остаётся на месте |
| M8 | Клип с «Боулдер», зацепками, слежением и подъёмами FIT — удалить клип перед ним | Плашка, зацепки, слежение, подъёмы FIT едут вместе с клипом и совпадают с картинкой |
| M9 | Связанный звук (Отделить звук → выделить видео и звук → Связать). Удалить клип перед ним | Видео и звук сдвигаются вместе |
| M10 | Переход между B и C; удалить B | Переход B–C пропадает (сообщение), новых переходов нет |
| M11 | Выключить магнит, удалить клип | Остаётся пропуск (как раньше); включить магнит — пропуски закрываются сразу, Ctrl+Z возвращает и пропуски, и выключенный магнит |
| M12 | Проект, сохранённый в 1.1 (до Phase 50) | Открывается с выключенным магнитом, клипы на месте |
| M13 | Проект только с V1, «Текст» или «Шаблон» | Появляется дорожка V2 с текстом/шаблоном (V1 не трогается); Ctrl+Z убирает и текст, и дорожку |

## Часть B2. Цветокоррекция (D069 §7)

| # | Действие | Ожидание |
|---|---|---|
| C1 | Выделить видеоклип | В Inspector (группа «Клип») раздел «Цвет»: «Автоулучшение» и 8 строк — Экспозиция, Яркость, Контраст, Света, Тени, Насыщенность, Температура, Оттенок (слайдер и поле −100…+100) |
| C2 | Потянуть «Температура» вправо, затем влево | Картинка теплеет / холодеет сразу в Preview; одно Ctrl+Z отменяет всё перетаскивание |
| C3 | «Насыщенность» −100 | Чёрно-белая картинка; плашки, текст, контуры зацепок не меняют цвет |
| C4 | Настроить несколько слайдеров, экспортировать | В файле экспорта цвета как в Preview |
| C5 | «Автоулучшение» на тёмном / синеватом клипе | Через секунду-две слайдеры выставлены (экспозиция вверх, температура теплее), картинка изменилась; одно Ctrl+Z возвращает всё |
| C6 | «Сбросить» в заголовке раздела «Цвет» | Все слайдеры 0, картинка исходная, одно Ctrl+Z возвращает |
| C7 | Разрезать клип / дублировать / копировать-вставить | Обе части и копии с той же цветокоррекцией |
| C8 | Сохранить, закрыть, открыть | Цветокоррекция на месте; HDR-клип с коррекцией выглядит так же |
| C9 | Фон «Размытие» у вертикального клипа с коррекцией | Размытый фон тоже с коррекцией |

## Часть B3. Новые переходы (D069 §8)

| # | Действие | Ожидание |
|---|---|---|
| T1 | Выделить склейку двух видеоклипов (с запасами), кнопка «Переход» | Меню из 13 переходов: у каждого значок-схема, название и строка о том, что он делает |
| T2 | По очереди: Размытие, Вытеснение, Круг, Шторки, Отдаление, Вращение, Смахивание, Глитч; проиграть склейку | Размытие — картинка расплывается к склейке и проявляется; Вытеснение — край идёт справа налево и открывает B; Круг — B в растущем круге; Шторки — B открывается от середины в стороны; Отдаление — картинка уменьшается (вокруг чёрное) и вырастает; Вращение — поворот к склейке; Смахивание — быстрый сдвиг с размытием; Глитч — расслоение цветов и рывки |

| T4 | Вытеснение / Круг / Шторки / Смахивание на клипах без запасов | Отказ с причиной (нужны запасы, как у наплыва и сдвига) |
| T5 | Экспортировать отрезок с несколькими новыми переходами | В файле переходы как в Preview |
| T6 | Сохранить, открыть | Типы и направления на месте |
