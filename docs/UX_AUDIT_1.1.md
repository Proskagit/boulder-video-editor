# UX-аудит 1.1 — проход по сценарию, дизайн-система, список изменений

Дата: 2026-11-18. Phase 49 / D068 §4–§5. Статус: **предложение; список изменений и их порядок утверждает владелец**, после чего шаги записываются в D068 как поправки.

Сборка: `feat/phase-49-ux` (Debug), экран 3440×1440. Тестовый проект — копии двух клипов 4K 60 к/с из `VideosForTest/12x10` во временной папке; реальные проекты не трогались. Аналоги — `docs/UX_CAPCUT_RESEARCH.md`, часть 2.

## 1. Проход по основному сценарию

Путь из `docs/TARGET_WORKFLOW.md`: импорт → разметка зацепок → FIT и трассы → шаблон → экспорт. Для каждого шага отмечено, где много кликов (**К**), где непонятно (**Н**) и где нет обратной связи (**О**).

| Шаг | Что происходит | Замечания |
|---|---|---|
| Запуск | Сразу пустой «Новый проект». Чёрный прямоугольник Preview, пустой Inspector с мелкой подсказкой | **Н** Нет первого экрана: что делать и где недавние проекты, не видно |
| Импорт | «+ Импорт» → системный диалог → 2 файла в «Медиа». Статус: «Импортировано 2 медиафайла» | **К** После импорта ничего не выделено, «На таймлайн» неактивна: выделить → нажать. **Н** Шкала пустого таймлайна — 10 минут |
| На таймлайн | Выделить оба → «На таймлайн». Частота проекта ставится по первому файлу, это сказано в статусе | **О** Таймлайн не подстраивает масштаб: 21 с материала — полоска в начале 10-минутной шкалы; нужно нажать «Вместить». **Н** На клипах нет кадров-миниатюр (D058 §7) |
| Выделение клипа | Inspector: «Трансформация и кадрирование» (открыт, длинный), «Слежение и люди», «Зацепки», «Появление…», «FIT», «Звук», «Клип» | **Н** Главный раздел «Зацепки» — третий, под длинным «Трансформация». Кнопка «Следить за скалолазом отсюда» стоит выше переключателя «Следить за скалолазом». При выделении двух клипов поля обрезаются справа («Вписать в к…», «Без звук…») |
| Разметка зацепок | «Разметить зацепки» → режим; подсказка мелким текстом в шапке Preview, лупа | **О** Первый щелчок, пока модель грузилась, пропал без следа. **Н** Режим почти не заметен: нет рамки вокруг Preview, подсказка 11 px серым. | FIT | Не проверялся вживую: тестового FIT-файла рядом с копиями нет | — |

| Настройки | Окно с разделами слева | **Н** Язык «Как в конфигурации» — непонятно пользователю. Фон окна чёрный, а у главного окна серый |

## 2. Аудит по скриншотам

### 2.1 Цвета, шрифты, отступы

- **Цвета:** в разметке (`src/UI/**/*.axaml`) 72 разных шестнадцатеричных цвета, 277 вхождений; общих ресурсов темы (`ResourceDictionary`) нет — каждый вид задаёт свои.
- **Синий** `#007ACC` значит сразу три вещи: «включено» (Привязка), «просто сообщение» (вся строка состояния), выбранная вкладка.
- **Фон окон:** главное окно серое; «Экспорт», «Настройки», «Справка» — почти чёрные (фон окна не задан, берётся тема по умолчанию).
- **Шрифты:** 7 размеров (9, 10, 11, 12, 13, 15, 20); основной — 10–11 px (148 из 162 мест). На большом мониторе подписи и подсказки читаются с трудом.
- **Отступы:** 52 разных значения `Margin`.

### 2.2 Значки вместо текстовых кнопок

- Панель инструментов: 11 текстовых кнопок; значки только у «Отменить» и «Повторить».
- Над таймлайном: около 20 кнопок в одну строку — значок + текст, половина неактивна без выделения; «Сегменты в плашке» видна только в Debug.
- Заголовки дорожек: 8 крошечных кнопок без подписей в колонке ~46 px, подпись дорожки (V1, A1) почти не видна.
- Свой набор `Icons.cs` (~40 контуров) — нарисован в проекте, единый по стилю (линии 1,5 px), но покрывает не всё.

### 2.3 Иерархия панелей

- Inspector: порядок разделов не следует основному сценарию (см. §1). Заголовки разделов — тёмные полосы заглавными буквами 10 px.
- Таймлайн занимает много пустого места внизу при двух дорожках.

### 2.4 Пустые состояния и стартовый экран

- Пустые «Медиа» и «Таймлайн» — подсказки есть, текст понятный, но мелкий и серый.
- Preview пустого проекта — просто чёрный прямоугольник.
- Стартового экрана нет (см. исследование, §2 «Стартовый экран»).

### 2.5 Прогресс и сообщения об ошибках

- Ошибки и информация — одна синяя строка внизу; сообщение остаётся, пока его не сменит следующее (после импорта в строке долго висит «Частота кадров проекта установлена…»).
- Долгие действия (загрузка модели, привязка к стене, анализ людей) показывают состояние в своих местах (шапка Preview, раздел Inspector) — разными цветами и шрифтами.

### 2.6 Горячие клавиши

- Набор полный и в духе CapCut / Premiere (S, Q/W, I/O, J/K/L, Ctrl+…), теперь есть справка (F1). Клавиши видны в подсказках кнопок, но не во всех.

## 3. Дизайн-система (предложение)

Одна тёмная тема в `src/UI/Themes/` (`ResourceDictionary` + стили), подключённая в `App.axaml`; виды берут цвета и размеры только оттуда. Внешний вид продукта меняется (рабочие процессы — нет).

### 3.1 Цвета (токены)

| Токен | Значение | Где |
|---|---|---|
| `Surface0` | `#16191D` | Фон окон (все окна одинаково) |
| `Surface1` | `#1E2328` | Панели (Медиа, Inspector, таймлайн) |
| `Surface2` | `#262C33` | Заголовки разделов, поля ввода, кнопки |
| `Border` | `#323A42` | Разделители |
| `TextPrimary` | `#E6E8EA` | Основной текст |
| `TextSecondary` | `#9AA3AB` | Подписи, подсказки |
| `Accent` | `#43A047` (зелёный иконки и трассы) | Только главное действие места: «Экспорт», «Экспортировать», «Создать проект», выбранная вкладка |
| `AccentText` | `#81C784` | Акцентный текст (подзаголовки справки, активный режим) |
| `Info` / `Warning` / `Danger` | нейтральный / `#F9A825` / `#E53935` | Сообщения: значок и полоса слева |
| `Selection` | `#2F6FB0` | Выделенные клипы и элементы списков |

Зелёный — цвет бренда; оранжевый трассы остаётся только цветом данных (контуры, плашки), не интерфейса.

### 3.2 Типографика

Шрифт — Inter (уже подключён: `WithInterFont`). Четыре размера вместо семи: **12** — подписи и подсказки, **13** — основной текст и кнопки, **15** — заголовки разделов, **20** — заголовки окон и пустых состояний. Два веса: обычный и полужирный. Заглавные буквы в заголовках разделов — отказаться (обычный регистр, полужирный).

### 3.3 Отступы и размеры

Шаг 4 px: отступы 4 / 8 / 12 / 16 / 24. Высота кнопок и полей — 28 px, значковая кнопка 28×28, скругление 4 px.

### 3.4 Значки

- **Кандидат — Lucide** (лицензия ISC, разрешает использование и изменение с сохранением уведомления; ~1 500 значков; контурный стиль 24×24 / 2 px, близкий к нашему `Icons.cs`). Подключаются как данные контуров в `Icons.cs` (без пакета-зависимости), уведомление — в `THIRD-PARTY-NOTICES`.
- Альтернатива — Tabler Icons (MIT), тот же стиль.
- Перед внедрением: проверить лицензию в репозитории выбранной версии и записать в D068 (правило «ни одной зависимости без проверки лицензии»).

## 5. Как внедрять

Шаги идут по номерам (P1 → P2 → P3), каждый — отдельный коммит `Phase 49 / D068 step N`, со скриншотами «до» / «после» в `docs/ux-1.1/` (до — сделаны в этом аудите), с прогоном сборок и тестов. Справка (D068 §3) дописывается в конце, когда интерфейс устоится. После P1 и P2 — ручная проверка владельца; P3 — по готовности.
