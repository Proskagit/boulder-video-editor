# AI Video Editor 1.0 — описание релиза (черновик для GitHub Release `v1.0.0`)

Первый релиз видеоредактора для роликов о боулдеринге (DECISIONS.md D066). Портативная версия для Windows 10 / 11 x64:
установка не нужна, .NET и FFmpeg входят в папку.

## Что внутри

- Монтаж: несколько дорожек видео и звука, обрезка, разрез, скорость, Undo / Redo, маркеры, магнитные привязки,
  ключевые кадры трансформации, предпросмотр, равный экспорту.
- AI-разметка зацепок по щелчку (SAM 2.1) с плавными контурами, анимация трассы, отслеживание зацепок при движении камеры.
- Follow — кадр следует за выбранным скалолазом; Occlusion — контуры зацепок скрываются за людьми.
- Тренировка из FIT-файла часов (COROS, Garmin и другие): трассы, номер, категория и статус, пульс в кадре.
- Текст с анимацией, переходы, шаблоны («Боулдер», «Хайлайт», REC, VHS), размытый фон для вертикального видео.
- Звук: линия громкости с точками, микшер, Solo, мастер, приглушение музыки под речь, шумоподавление и улучшение голоса.
- Экспорт в MP4 (H.264) с пресетами разрешения, на видеокарте NVIDIA через NVENC; таймкоды для описания на YouTube.

## Файлы

| Файл | Что это |
|---|---|
| `AiVideoEditor-1.0.0-win-x64.zip` | Редактор: распаковать и запустить `AiVideoEditor.exe` |
| `AiVideoEditor-1.0.0-models.zip` | AI-модели (≈ 1,2 ГБ): распаковать и запустить `Install-Models.cmd` |
| `aive-ffmpeg-minimal-9.0.2-sources.tar` | Полный исходный код входящей в поставку сборки FFmpeg (GPL-2.0-or-later) |
| `SHA256SUMS` | Контрольные суммы файлов |

## Требования

Windows 10 или 11, 64-бит. Для NVENC — видеокарта NVIDIA с драйвером 551.76+. Для разметки зацепок и Occlusion на
видеокарте — DirectX 12 (DirectML); без неё разметка работает на процессоре, Occlusion недоступен.
