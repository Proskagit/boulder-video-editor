2. HOW TO REBUILD
-----------------
On Linux with Docker:

  tar -xf aive-ffmpeg-minimal-9.0.2-sources.tar -C sources
  docker build -t aive-ffmpeg-toolchain sources/recipe
  docker run --rm --network=none -v "$PWD/sources/recipe:/recipe:ro" -v "$PWD/sources:/sources:ro" \
      -v "$PWD/out:/out" aive-ffmpeg-toolchain bash /recipe/build.sh

The toolchain image is pinned by the Debian base image digest and a snapshot.debian.org date (see
recipe/Dockerfile). The build runs without network and is expected to reproduce the SHA-256 values above.
