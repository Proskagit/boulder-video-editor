# Boulder Video Editor 1.3.0

Видеоредактор для роликов о боулдеринге для Windows 10 / 11 x64. Теперь его можно поставить установщиком (DECISIONS.md
D070); .NET, FFmpeg и ИИ-модели уже входят в поставку, ставить что-то отдельно не нужно.

## Какой файл скачать

| Файл | Что это |
|---|---|
| `BoulderVideoEditor-1.3.0-setup.exe` (≈ 1,2 ГБ) | **Полный установщик**: программа и ИИ-модели. Интернет не нужен. |
| `BoulderVideoEditor-1.3.0-web-setup.exe` (≈ 50 МБ) | **Лёгкий установщик**: программа; ИИ-модели скачиваются при установке (≈ 1,2 ГБ) из релиза `models-1.0`, каждый файл проверяется по SHA-256. |
| `BoulderVideoEditor-1.3.0-win-x64-portable.zip` (≈ 1,2 ГБ) | **Портативная версия**: распаковать целиком и запустить `BoulderVideoEditor.exe`; модели в папке `ai-models\`, при первом запуске редактор предложит их установить. |
| `aive-ffmpeg-minimal-9.0.2-sources.tar` | Полный исходный код входящей в поставку сборки FFmpeg (GPL-2.0-or-later). |
| `SHA256SUMS` | Контрольные суммы файлов. |

## Установка, обновление, удаление

- Установщик ставит программу для текущего пользователя, права администратора не нужны (по умолчанию в
  `%LOCALAPPDATA%\Programs\Boulder Video Editor`), создаёт ярлыки в меню «Пуск» и, если отмечено, на рабочем столе.
- Обновление — установщик новой версии поверх старой: та же папка, вторая копия не появляется; настройки, проекты и
  модели сохраняются, правильные модели не копируются и не скачиваются заново.
- Удаление — «Параметры» → «Приложения». Проекты, видео, экспорты и настройки не удаляются никогда; ИИ-модели — только если
  отметить «Также удалить ИИ-модели».
- Установщик не подписан: SmartScreen может показать «Неизвестный издатель» — «Подробнее» → «Выполнить в любом случае».

## Что нового с 1.0

- Новое имя и значок, справка внутри программы (F1), тёмная тема, стартовый экран, обновлённый Inspector.
- Магнитная основная дорожка, цветокоррекция с «Автоулучшением», восемь новых переходов (до 5 с, без запаса исходника).
- Установщик, лёгкий web-установщик, портативная версия одним архивом с установкой моделей из программы.
- Исправлено: строки недавних проектов на стартовом экране больше не «выделяются» все разом при открытии одного из них.

## Требования

Windows 10 или 11, 64-бит. Для NVENC — видеокарта NVIDIA с драйвером 551.76+. ИИ-функции работают на видеокарте через
DirectML (DirectX 12), без неё — на процессоре (медленнее).

## Лицензии

Сторонние компоненты — `THIRD-PARTY-NOTICES.txt` и `licenses\` в папке программы; FFmpeg — `ffmpeg\THIRD-PARTY-NOTICES.txt`, его
исходный код — `aive-ffmpeg-minimal-9.0.2-sources.tar` этого релиза; ИИ-модели (Apache-2.0 / MIT) — `models-licenses\`
(установщик), `ai-models\` (портативная версия) и релиз `models-1.0`.
