# R2 → E — компенсация движения камеры: план ручной проверки

Решение: DECISIONS.md D052 (K1–K3, D4 утверждены 2026-11-08; порог точности 3 px при 1920 утверждён 2026-11-08). Запись этапа:
`docs/PHASE_HOLD_TRACKING.md` §19. Автоматические доказательства (тесты, реальные клипы, паритет Preview / экспорт) —
там же; здесь только то, что требует глаз и рук владельца.

Окружение: сборка ветки `feat/r2e-tracking-completion` (или `main` после её слияния); клипы сессии 27.09 и HDR-пилот.
Исходники только читаются: проект создаётся новый, клипы импортируются, ничего не перезаписывается.

Обозначения: **PASS** — критерий выполнен; **FAIL** — дефект; **NOT RUN** — не проверялось, с причиной.
