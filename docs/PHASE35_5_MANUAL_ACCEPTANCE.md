  **не существует** (проверено 2026-11-03). Приложение создаёт или меняет его **только при сохранении проекта**
  (Phase 37: каждое «Сохранить» / «Сохранить как» проекта с FIT-метками добавляет наблюдения, сбор Beta включён по

## 3. Подготовка проекта и тренировки (обязательные шаги)

Без шагов 3.2–3.5 накладка ничего не покажет. Это правильное поведение: пульсу нужны тренировка и начало записи
видео (Z).

### 3.1. Новый проект и видео

1. На панели инструментов нажмите **«Создать»** (Ctrl+N). Если появится вопрос «Несохранённые изменения», выберите
   «Не сохранять».
2. **«Импорт медиа»** (Ctrl+I) → выберите `D:\Времянка для монтажа\Боулдер 27.09.2026\video_20260927_111424.mp4`.
   - Ожидается: файл появился в панели медиа, через несколько секунд показаны его сведения (длительность 4:29,
     3840 × 2160).
3. Выделите файл в панели медиа → **«На таймлайн»**.
   - Ожидается: клип на дорожке **V1**, начиная с 00:00:00.
   - Если появится вопрос «Холст проекта», выберите «Оставить»: для проверки холст не важен.
4. Под дорожками нажмите **«+ Видеодорожка»**.
   - Ожидается: появилась пустая дорожка **V2** над V1. Она нужна, потому что шаблон всегда встаёт на верхнюю
     видеодорожку, а накладка берёт пульс из видео **под** собой.

### 3.2. Импорт FIT

1. На панели инструментов откройте **«Тренировка COROS…»** → **«Импортировать…»**.
2. В окне «Импорт тренировки COROS» выберите **копию**
   `C:\Users\Vlad\Desktop\Проверка 35.5\fit\Болдеринг20260927100239.fit`.

Ожидается в строке состояния: «Тренировка импортирована: COROS APEX 4 42mm, 27.09.2026 10:02–11:39 (UTC+03:00), 14
подходов».

### 3.3. Убедиться, что тренировка импортирована

- Наведите курсор на кнопку **«Тренировка COROS…»**. В подсказке должно быть «Тренировка проекта: COROS APEX 4 42mm, 27.09.2026 …», имя
  файла `Болдеринг20260927100239.fit` и «Файл доступен.».
- Откройте меню «Тренировка COROS…». Должно появиться поле **«Поправка часов тренировки, кадры»** со значением 0. Не
  меняйте его (кроме проверки Д3).

### 3.4. Задать начало записи видео (Z) — обязательно

Без Z у видео нет связи с часами: Inspector пишет «Начало записи этого видео: неизвестно», а накладка над ним ничего
не рисует.

1. Щёлкните по клипу на V1, чтобы выделить его. В Inspector появится раздел **«ТРЕНИРОВКА COROS»** с текстом «Начало
   записи этого видео: неизвестно».
2. Поставьте плейхед на кадр последнего касания стены при соскоке с подъёма 12 — около **1:31** от начала клипа
   (в разметке 35.3R2 это 91,2 с). Щёлкните по линейке времени рядом с 00:01:31, затем подведите точнее: **→ / ←**
   — на кадр, **Shift+→ / Shift+←** — на секунду.
3. В списке подъёмов Inspector выберите **«Подъём 12 · 11:15:48–11:16:02»**.
4. «Точка привязки» — оставьте **«Конец подъёма»** (по умолчанию).
5. Нажмите **«Совместить кадр с концом подъёма»**.

Ожидается:
- в строке состояния: «Начало записи задано по концу подъёма 12.»;
- в Inspector: «Начало записи этого видео: задано по подъёму»;
- на клипе могут появиться FIT-метки старта трасс (это Phase 37, на проверку пульса не влияют).

Это одно действие Undo. Ctrl+Z вернёт «неизвестно», Ctrl+Y — снова «задано».

### 3.5. Убедиться, что приложение получает пульс для этого видео

Не снимая выделения с клипа V1, посмотрите под кнопками раздела «ТРЕНИРОВКА COROS» строку
**«Тренировка в позиции плейхеда: …»**:

| Плейхед на V1 | Что должно быть в строке |
|---|---|
| около 0:30 | «Тренировка в позиции плейхеда: 11:14:5x (часы) · NNN уд/мин» |
| около 1:31 (кадр соскока) | время часов около 11:15:57 (конец подъёма 11:16:02 минус задержка 4,6 с) и BPM |
| около 4:00 | «Тренировка в позиции плейхеда: 11:18:2x (часы), нет данных пульса» — это пауза таймера |

Строка обновляется при каждом перемещении плейхеда. Если она показывает время часов и BPM, синхронизация для этого
видео есть.

## 5. Подробности к экспорту и сравнению

### 5.1. Запуск экспорта

Кнопка **«Экспорт»** на панели инструментов или **Ctrl+E**. Порядок окон:
1. Если на таймлайне заданы точки входа и выхода — вопрос «Экспортировать только диапазон или весь таймлайн?». Для
   этой проверки выберите «Весь таймлайн».
2. Если есть предупреждения — окно **«Предупреждения экспорта»**: «Экспорт возможен, но обратите внимание:», список
   предупреждений, «Продолжить экспорт?», кнопки **«Продолжить»** и **«Отмена»**. Это окно появляется **до** выбора
   файла.
3. Окно выбора файла «Экспорт — выберите файл».
4. Окно прогресса, затем «Экспорт завершён».

### 5.2. Как выглядят предупреждения о пульсе

Каждое из них появляется, только если в экспортируемом диапазоне есть накладка «Пульс». Без накладки тренировка на
экспорт никак не влияет (проверка Д5).

| Ситуация | Текст предупреждения |
|---|---|
| В проекте нет тренировки | «У накладки пульса нет данных: в проекте нет тренировки COROS. В экспорте она ничего не покажет.» |

### 5.3. После «Продолжить»

Экспорт идёт как обычно. Там, где у накладки нет данных, в файле её **просто нет**: не выводятся ни число, ни «0»,

## 7. Что нельзя проверить через интерфейс (ограничения)

- **Пропуски замеров дольше 2 с вне паузы.** В FIT 27.09 их нет: из 5 769 записей пульс есть в 5 766, и единичные
  пропуски короче 2 с, поэтому значение там держится. Правило «нет значения после 2 с без замера» проверено
  автотестами (`HeartRateOverlayTests`); вручную на этих данных его не воспроизвести.
- **Побайтное равенство Preview и экспорта** — только автотестами (`HeartRateRenderTests`,
  `ExportHeartRateEndToEndTests`). Вручную — совпадение показанного (О13).
- **Перетаскивание накладки мышью по кадру** не предусмотрено: положение задаётся четырьмя кнопками.
- **Размер накладки** не настраивается: он зависит от размера кадра.
- **Слоу-мо и таймлапс** (видео не в реальном времени) не поддерживаются для синхронизации с тренировкой (D051 §1.5).
- Не входит в Phase 35.5: экспорт тайм-кодов и глав YouTube, FIT-дорожка на таймлайне, редактирование FIT-событий,
  автоматическое начало записи (35.3e), распознавание попыток по движению.
