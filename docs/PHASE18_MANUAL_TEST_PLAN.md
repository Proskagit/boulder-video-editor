# Phase 18 — manual test plan

Run in the real app (`dotnet run --project src/App/App.csproj`, ffmpeg / ffprobe on PATH unless the scenario says
otherwise). Written at Step 18.2 (D033, product owner decisions of 2026-10-13) as a skeleton; the steps that implement the
features complete the scenarios; Step 18.8 runs them in the real app with the regression. Manual runs use an isolated
profile (`USERPROFILE` / `LOCALAPPDATA` / `APPDATA` pointed to a scratch folder), as in Phases 11–17, and UI Automation.
Every new control is checked at 1024 and 1440 px window width.

Footage: the product owner's files in `VideosForTest/` (never committed; excluded locally by `.git/info/exclude`). The
five comparison clips of the pre-flight: Vivo "боулдеринг нежные цвета контраст" (portrait, indoor), "бильярд много ламп
пересвет" (lamps, saturated blue), "квартира человек желтый свет" (warm light, skin), "city блекло" (daylight), Huawei "вода
трава солнечно" (sun, HDR Vivid, 30 fps). The pre-flight's reference moments: bouldering 71.9 s, apartment 5.4 s,
billiards 43.9 s (matched to the gallery screenshots); their expected look is the L2 renders of the pre-flight (kept in
the session's scratch folder), not the screenshots. Synthetic fixtures (HLG; PQ with and without mastering / CLL; SDR)
are generated by the automated tests. Builds: the Phase 18 build; for the regression the Phase 17 build of `main`
(`fa96468`, built from `git archive`).

Status column — kinds of evidence, never mixed:
- **auto (18.x)** — covered by automated tests only, not checked in the real app;
- **18.8 (Claude): PASS / FAIL / NOT RUN** — the formal Step 18.8 run in the real app;
- **PO** — run by the product owner.
