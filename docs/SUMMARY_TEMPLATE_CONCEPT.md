# Шаблон «Итоги» — концепция владельца (2026-11-19)

Записано со слов владельца продукта во время подготовки Phase 53 (маршрут от первой зацепки), чтобы учесть в фазе
«Итоги» (пункт 3 очереди после 1.3.0; бэклог 36.3 `PassId`, 36.4 пульс в сводке). Это **концепция, а не решение**:
решение (D0xx) пишется в начале той фазы, вопросы задаются тогда же.

## Что это

Оверлей-шаблон с анимированной краткой сводкой тренировки / дня / проходки. Длительность по умолчанию — **10 с**.

## Анимация

1. Появляется **шапка** с анимацией: «Итоги дня», «Итоги тренировки», «Итоги проходки» — формулировку придумать.
2. Под шапкой **раскрывается фон**, параллельно появляются строки — по одной на трассу.
3. Строка трассы, например: «Трасса № 1, сложность …, пройдена за N с», пульс средний и максимальный, результат
   (топ, попытка и т. п.).
4. Высота строк — сначала одно стабильное значение по умолчанию, которое нормально читается на кадре.
5. **Прокрутка**, если трасс больше, чем влезает (например, влезает 10): при появлении 11-й список сдвигается, первая
   трасса уезжает вверх и пропадает за шапкой.

## Данные

- **Время трассы** = от **конца оранжевой области** до **начала фиолетовой области** — чистое время подъёма.
- Пульс: средний и максимальный за это время (правила пульса D055 / D062: без Z, CC — единственная поправка).
- Результат проходки: топ / попытка и т. п. (только из данных, как они есть — D062).
- Стиль — **под существующий шаблон болдера** (то, как сейчас подписываются трассы).

## Ориентир

Посмотреть, как подводят итоги на чемпионатах мира по боулдерингу, и взять оттуда идеи оформления (без копирования
чужой графики и бренда).
