# Phase 27 — manual test plan

Manual checks of the text animation and readability (DECISIONS.md D043). Run in the real app on Windows with the default
`appsettings.json` (`App:Language` = `ru`) unless a row says otherwise, at **1024 × 640** (the window's minimum) and
**1440 × 900** (the default), in Avalonia's logical pixels. Media: the product owner's portrait gym clip in `VideosForTest`
and a Phase 26 v6 project with text clips (with and without fades) saved by the Phase 26 build (`41dadf2`).

Status column — kinds of evidence, never mixed:
- **auto** — covered by automated tests only, not checked in the real app;
- **local (Claude)** / **PO** — the real-app run on Windows / the product owner's check;
- **harness** — the real Phase 26 and Phase 27 code run side by side outside the app (a console tool, the export's rasterizer);
- **NOT RUN** — not checked in the real app (the reason given).

Run on 2026-10-20 by Claude on Windows 11 (OS UI culture ru-RU, display at 125 %), the Debug build of the branch at
`7fb0d3d` copied to the session's scratch folder, driven by UI Automation (Invoke / Toggle / Selection patterns, the native
dialogs by window messages) and two mouse clicks on the ruler and the clip (only with the app in front); results read from
UI Automation, window screenshots (PrintWindow), the saved `project.json` and the exported MP4 (ffprobe, frames extracted
with ffmpeg and looked at). An empty project (no media): the canvas 1920 × 1080, 30 fps; logs and the recent list under the
real `%LOCALAPPDATA%\AiVideoEditor`. **Side effect of the run:** one automation step pressed «Справка» in the native save
dialog, which opened a Windows help search in the user's Microsoft Edge — left open (not ours to close).
