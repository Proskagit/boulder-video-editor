# Phase 22 — manual test plan

Manual checks of the timeline selection, the magnetic snapping and the making of room (DECISIONS.md D037). Run in the real
app on Windows with an isolated profile as in Phases 11–21. Fixture: a project with V1, V2, A1 (and A2 for the linked rows),
several video clips with their own sound, one unlinked pair (Unlink Audio) with gaps around it, a dissolve between two clips
of V1, a text clip on V2, and one locked track for the lock rows. Window widths 1024 and 1440 px.

Run on 2026-10-15 / 16 by Claude (Step 22.6) on Windows 11, the Debug build of `f4383c3`, the Phase 10 fixture
(`tools/manual/New-Phase10DissolveFixture.ps1`, 25 fps, extended in the app: a linked pair, dissolves, a locked track, a
20-minute copy for the export and auto-scroll rows), driven by UI Automation and system mouse / keyboard input; every result
read from the saved `project.json`, the status bar, the Inspector and screenshots. Not isolated: the app writes its logs,
recovery files and the recent-projects list under the real `%LOCALAPPDATA%\AiVideoEditor` (`LOCALAPPDATA` in the environment
does not move it) — the fixture was added to "Recent".

- **auto** — covered by automated tests only, not checked in the real app;
