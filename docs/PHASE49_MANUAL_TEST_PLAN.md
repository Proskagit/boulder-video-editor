# Phase 49 — план ручной проверки (D068: UX 1.1 — название, иконка, справка, аудит интерфейса)

Сборка: portable `artifacts/portable/BoulderVideoEditor-<версия>-win-x64` из `feat/phase-49-ux`. Каждая строка: действие →
ожидание. План дополняется по шагам фазы.

## Шаг 1. Название и иконка (D068 §1–§2)

| # | Действие | Ожидание |
|---|---|---|
| 1a | Запустить `BoulderVideoEditor.exe` | Заголовок окна «Без названия — Boulder Video Editor» (или имя проекта) |
| 1b | Посмотреть на заголовок окна, панель задач и exe в Проводнике | Везде новая иконка: зелёная зацепка в белом контуре на тёмном квадрате |
| 1c | Перед первым запуском 1.1 закрыть 1.0; убедиться, что есть `%LOCALAPPDATA%\AiVideoEditor` (настройки, модели, недавние проекты). Запустить 1.1 | Папка `%LOCALAPPDATA%\AiVideoEditor` исчезла, всё лежит в `%LOCALAPPDATA%\BoulderVideoEditor`; недавние проекты, настройки (язык, сглаживание) и раскладка панелей — как были; разметка зацепок работает (модели на месте) |
| 1d | Повторить 1c, но сначала установить модели 1.1 (`Install-Models.cmd` из архива 1.1), потом запустить | Новая папка уже была — старая слита в неё: настройки и недавние проекты на месте; если в старой осталось то, что уже было в новой, старая папка остаётся (ничего не удалено), в журнале `app-*.log` строка «Moved the old per-user folder…» |
| 1e | Открыть проект, сохранённый в 1.0 | Открывается как раньше |

## Шаг 2. Справка внутри программы (D068 §3)

| # | Действие | Ожидание |
|---|---|---|
| 2a | Нажать «?» справа на панели инструментов | Открывается окно «Справка — Boulder Video Editor»: слева темы, справа «Начало работы» |
| 2b | Нажать F1 в главном окне — в том числе когда курсор в текстовом поле | Окно справки открывается (или выходит на передний план, если уже открыто); в поле ничего не печатается |
| 2c | Выбрать темы «Разметка зацепок», «Горячие клавиши» | Текст читается, жирным выделены названия кнопок и клавиши; новая тема открывается с начала |
| 2d | Ввести в поиск «экспорт», затем бессмыслицу, затем очистить | Сначала остаются темы, где есть это слово; затем «Ничего не найдено…»; после очистки — все темы |
| 2e | Не закрывая справку, поработать в главном окне; затем Esc в окне справки | Главное окно работает (справка не модальная); Esc закрывает справку |
| 2f | Переключить язык на английский в «Настройки…», перезапустить, открыть справку | Справка на английском, те же темы |
| 2g | Пройтись по текстам | Всё соответствует программе; неточности и пожелания — замечаниями (тексты финализируются в конце фазы) |
