# Phase 59 — ручная проверка: события попытки по видео (D078)

Проверять на **копии** проекта с тренировкой и FIT (например, копия «Новый проект» за 27.09 — авторазметка часами), на компьютере
с видеокартой. Анализ идёт в фоне; после первого прогона он берётся из кеша.

| № | Шаги | Ожидается |
|---|---|---|
| 1 | Настройки → «FIT-тренировки»: подраздел «Срывы и отрывы по видео» (окно 1024 и 1440 px) | «Уточнять конец срыва по видео» — включено, «Притягивать начало трассы к отрыву» — выключено; под каждым флажком — пояснение |
| 2 | Новый проект: видео тренировки → импорт FIT (области трасс создаются как раньше) → подождать 3–5 минут, не трогая области | В строке состояния «Области трасс уточнены по видео: N». У областей со статусом «Попытка» лиловая область начинается в момент срыва (просмотреть 2–3 трассы кадр за кадром: ошибка обычно ≤ 1 с); у «Топ» / «Flash» ничего не сдвинуто |
| 3 | После п. 2 Ctrl+Z | Уточнённые области одного видео возвращаются к раскладке FIT одним шагом (по шагу на видео); уточнение не повторяется само до повторного открытия проекта |
| 4 | Изменить одну область руками (перетащить её край) до окончания анализа | Эта область не уточняется, остальные — да |
| 5 | Включить «Притягивать начало трассы к отрыву», открыть проект заново | Начало трассы `T` (синяя метка) у части областей сдвигается не больше чем на 3 с к моменту отрыва ног; проверить на 3–4 трассах |
| 6 | На клипе с оранжевой областью (зацепки размечены, «Готово») перетаскивать конец оранжевой около отрыва | Конец «прилипает» к найденному отрыву (видна линия привязки); с выключенной настройкой — обычная привязка |
| 7 | Выключить обе настройки, открыть проект с FIT | Ничего не анализируется ради событий, области — по FIT |
| 8 | «Шаблон» → «Боулдер», когда плейхед над видеоклипом | Шаблон стоит над клипом, зелёный, с лиловой областью на последних 5 с, ручками полосы и пульсом (как область трассы); статус «Попытка» виден только в лиловой части |
| 9 | «Шаблон» → «Боулдер», когда плейхед вне видеоклипов | Свободный шаблон, как раньше |
| 10 | На компьютере без видеокарты (или с отключённой) — п. 2 | Одно сообщение «Поиск срывов и отрывов по видео работает только с видеокартой — области трасс остаются по FIT.»; Follow работает как раньше |
| 15 | Удалить у трассы «Боулдер» и разметку, затем «Распознать прохождения из FIT» на клипе | Область создаётся заново; через несколько секунд (анализ из кеша) у неё появляется лиловая область со срыва и статус «Попытка» (если не «Топ» от часов) |
| 16 | Новый проект, первым добавить 4K-видео 16:9 | Размер кадра проекта сразу 3840 × 2160 (сообщение в строке состояния); Ctrl+Z убирает клип и возвращает 1920 × 1080 |
| 17 | Медиабраузер: выделить 3 файла (Ctrl+щелчок или рамкой), правый щелчок по любому из них → «Удалить из проекта»; затем рамкой выделить 2 файла и нажать Delete | Один вопрос про все выделенные файлы, удаляются все; опустевшие дорожки V2… удаляются вместе с ними; Delete после рамки работает |
| 18 | Импорт FIT с видео 27.09 (110133 и 103026) | У 110133 две соседние области стоят встык на одной дорожке; у 103026 появляется область подъёма 5 (10:31:21–10:31:53); новые дорожки не повторяют имён |
| 19 | Заголовок окна | «… — Boulder Video Editor · версия 1.12.3» |
| 12 | Посмотреть правый верхний угол рядом с «Сохранено» | Всегда видно «ЦП … % · ГП … %», цифры обновляются раз в 1,5 с и похожи на диспетчер задач |
| 13 | Включить Follow на клипе (или импортировать FIT с включённой настройкой срыва) | Слева от загрузки — плашка «Анализ людей (Follow) N %» / «Поиск срывов и отрывов N %»: процент каждого прогона от 0 до 100, затем следующий; «+N» — сколько ещё в очереди, в подсказке все; плашка исчезает, когда анализ закончился |
| 14 | Разметить зацепки на клипе с движением камеры | Плашка «Трекинг зацепок» с бегущей полоской, пока трекинг идёт |
| 11 | Follow на клипе во время анализа событий | Анализ Follow идёт первым (событиям отдаётся оставшееся время), экспорт не ждёт анализа событий |

**Не проверяется автоматически:** точность на реальном видео (исследование: `docs/ATTEMPT_EVENTS_RESEARCH.md`), магнит в живом
перетаскивании (п. 6), сообщение без видеокарты на реальной машине (п. 10).
