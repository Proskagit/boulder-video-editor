# Boulder Video Editor 1.10.0

Видеоредактор для роликов о боулдеринге для Windows 10 / 11 x64. Этот выпуск собирает всё, что сделано после 1.3.0
(фазы 52–57): трасса от первой зацепки, шаблон «Итоги», удобство монтажа, гладкие контуры зацепок, стили текста и новый
экспорт — кодеки, форматы файла и пресеты.

## Какой файл скачать

| Файл | Что это |
|---|---|
| `BoulderVideoEditor-1.10.0-setup.exe` (≈ 1,2 ГБ) | **Полный установщик**: программа и ИИ-модели. Интернет не нужен. |
| `BoulderVideoEditor-1.10.0-web-setup.exe` | **Лёгкий установщик**: программа; ИИ-модели скачиваются при установке из релиза `models-1.0`, каждый файл проверяется по SHA-256. |
| `BoulderVideoEditor-1.10.0-win-x64-portable.zip` (≈ 1,2 ГБ) | **Портативная версия**: распаковать целиком и запустить `BoulderVideoEditor.exe`; модели в папке `ai-models\`, при первом запуске редактор предложит их установить. |
| `aive-ffmpeg-minimal-9.0.2-sources.tar` | Полный исходный код входящей в поставку сборки FFmpeg (GPL-2.0-or-later), теперь с x265 и SVT-AV1. |
| `SHA256SUMS` | Контрольные суммы файлов. |

Обновление — установщик 1.10.0 поверх 1.3.0: настройки, проекты и модели сохраняются. Проект, сохранённый в 1.10.0, более
старая версия не откроет (формат проекта v29).

## Что нового с 1.3.0

- **Экспорт: кодеки, форматы и пресеты.** H.264, HEVC и AV1 — на видеокарте NVIDIA (NVENC), а без неё на процессоре тем же
  кодеком; файл MP4, MOV или MKV. Четыре пресета: «Быстрый» (Full HD, H.264), «Средний» (2K, AV1 — самый маленький файл),
  «Высокий» (4K, H.264), «Максимальный» (размер проекта, H.264 — по умолчанию). В «Подробных настройках» видны все поля
  пресета; свои пресеты можно сохранить, они доступны во всех проектах; «?» подсказывает, какой кодек к какому качеству.
  Качество каждого кодировщика откалибровано по VMAF на видео со скалодрома, оценка размера учитывает кодек. Разрешение 2K.
- **Трасса от первой зацепки** («Предлагать трассу»): щелчок по одной зацепке — редактор предлагает остальные зацепки этой
  трассы, вы подтверждаете, добавляете или убираете.
- **Шаблон «Итоги»**: анимированная таблица трасс — результат, попытки, время, категория, пульс; статус FLASH; русский или
  английский текст.
- **Удобство монтажа**: кнопки «Обрезать слева / справа» (и Q / W без выделения), прокрутка окна экспорта, первые зацепки
  трассы сразу прячутся за людьми.
- **Контуры зацепок** без «зубчиков», острые углы треугольных зацепок сохраняются.
- **Стили текста**: курсив, тень, межстрочный интервал, ширина блока с переносом по словам (тянется в Preview), сохранённые
  стили.
- **Качество Preview** на его панели (Оригинал / 1440p / 1080p / 720p).

## Требования

Windows 10 или 11, 64-бит. Для NVENC — видеокарта NVIDIA с драйвером 551.76+ (AV1 на NVENC — видеокарты RTX 40 и новее).
Для воспроизведения HEVC и AV1 встроенным плеерам Windows нужны расширения из Microsoft Store; VLC, браузеры и YouTube
играют их без них. ИИ-функции работают на видеокарте через DirectML (DirectX 12), без неё — на процессоре (медленнее).
