# Phase 26 — manual test plan

Manual checks of the vertical video and framing (DECISIONS.md D041). Run in the real app on Windows with the default
`appsettings.json` (`App:Language` = `ru`) unless a row says otherwise, at **1024 × 640** (the window's minimum) and
**1440 × 900** (the default), in Avalonia's logical pixels. Media: the product owner's phone clips in `VideosForTest`
(Vivo X300 Pro, Huawei P60 Pro) — portrait and landscape, with and without rotation metadata — and generated fixtures where
a case needs a property the clips lack (a rotation tag, an odd size, an unknown orientation).

Status column — kinds of evidence, never mixed:
- **auto** — covered by automated tests only, not checked in the real app;
- **local (Claude)** / **PO** — the real-app run on Windows / the product owner's check;
- **NOT RUN** — not checked in the real app (the reason given).

Run on 2026-10-20 by Claude on Windows 11 (OS UI culture ru-RU, display at 125 %), the Debug build of the branch (Steps
26.1–26.3 and the non-breaking spaces in the offer's sizes), a copy of `bin` in the session's scratch folder, driven by UI
Automation and system mouse input; results read from UI Automation (the dialog's text, the status bar, the Inspector's
fields, the Project Settings dialog's «Сейчас: …» line), screenshots, the exported file (ffprobe, `cropdetect`, frames
looked at). Media: the product owner's clips in `VideosForTest` (whole files, and 4 s stream copies of «huawei p60 pro - лес
солнечно» and «vivo x300 pro - city блекло» that keep the rotation tag) and two fixtures made with ffmpeg from a 1080 × 1920
test pattern: `-display_rotation 45` (an odd angle) and `-display_hflip` (a mirrored matrix). Not isolated: logs and the
recent-projects list under the real `%LOCALAPPDATA%\AiVideoEditor`; every project closed with «Не сохранять».
