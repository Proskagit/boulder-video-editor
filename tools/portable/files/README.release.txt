AI Video Editor 1.0 — портативная версия для Windows
====================================================

Видеоредактор для роликов о боулдеринге: импорт, монтаж, AI-разметка зацепок и их анимация, трассы и пульс из
FIT-файла часов, текст, переходы, шаблоны, звук и экспорт в MP4.

Установка не нужна. Папку можно положить куда угодно (в том числе в путь с пробелами и русскими буквами)
и запускать оттуда. .NET и FFmpeg устанавливать не нужно — они входят в папку.

Требования
----------
- Windows 10 или 11, 64-бит (x64).
- Для быстрого экспорта через NVENC — видеокарта NVIDIA с драйвером 551.76 или новее (без неё экспорт идёт на
  процессоре, медленнее).
- Для AI-функций — архив моделей BoulderVideoEditor-1.0.0-models.zip (около 1,2 ГБ на диске), см. ниже.

Запуск
------
Запустите BoulderVideoEditor.exe.

AI-модели
---------
Модели поставляются отдельным архивом BoulderVideoEditor-1.0.0-models.zip:
1. Распакуйте его в любую папку.
2. Запустите Install-Models.cmd — модели скопируются в %LOCALAPPDATA%\BoulderVideoEditor\models с проверкой
   каждого файла.
3. Перезапустите редактор.
Без моделей редактор работает; недоступны только разметка зацепок, Follow / Occlusion и улучшение голоса /
приглушение музыки под речь — редактор сообщит об этом. Подробности: docs\AI_MODEL.md.

FFmpeg
------
В папке ffmpeg\ — минимальная сборка FFmpeg 9.0.2 для этого редактора (лицензия GNU GPL версии 2 или новее).
Её состав и лицензии: ffmpeg\THIRD-PARTY-NOTICES.txt; полный исходный код опубликован вместе с релизом
(aive-ffmpeg-minimal-9.0.2-sources.tar). Другую сборку FFmpeg можно указать в настройках редактора.

Где редактор хранит данные
--------------------------
%LOCALAPPDATA%\BoulderVideoEditor\ — журналы (logs), файлы восстановления (recovery), кэш, настройки, список
недавних проектов, модели. Проекты сохраняются туда, куда вы их сохраняете; свои данные редактор в папке
программы не хранит.

Журналы
-------
%LOCALAPPDATA%\BoulderVideoEditor\logs — при проблеме приложите файлы app-*.log, errors-*.log и ffmpeg-*.log.

Лицензии
--------
THIRD-PARTY-NOTICES.txt и папка licenses\ — сторонние компоненты этой сборки и их лицензии;
ffmpeg\THIRD-PARTY-NOTICES.txt — FFmpeg. BUILD-INFO.txt — версия, коммит и состав сборки.
