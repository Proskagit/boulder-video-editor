Boulder Video Editor {{VERSION}} — установленная версия для Windows
==================================================================

Видеоредактор для роликов о боулдеринге: импорт, монтаж, AI-разметка зацепок и их анимация, трассы и пульс из
FIT-файла часов, текст, переходы, цвет, звук и экспорт в MP4.

Эту папку создал установщик BoulderVideoEditor-{{VERSION}}-setup.exe. .NET и FFmpeg входят в неё; ИИ-модели установщик
положил в %LOCALAPPDATA%\BoulderVideoEditor\models.

Требования
----------
- Windows 10 или 11, 64-бит (x64).
- Для быстрого экспорта через NVENC — видеокарта NVIDIA с драйвером 551.76 или новее (без неё экспорт идёт на
  процессоре, медленнее). ИИ-функции работают на видеокарте через DirectML, а без подходящей видеокарты — на
  процессоре (медленнее).

Обновление
----------
Запустите установщик новой версии: он обновит программу в этой же папке (вторая копия не создаётся), настройки,
проекты и модели сохранятся; модели, которые уже установлены правильно, повторно не копируются.
Тот же установщик, запущенный ещё раз, восстанавливает повреждённые или удалённые модели.

Удаление
--------
«Параметры Windows» → «Приложения» → Boulder Video Editor → «Удалить». Удаляются файлы программы и ярлыки.
Проекты, видео, экспорты, настройки и кэш не удаляются никогда. ИИ-модели (около 1,2 ГБ) удаляются, только если
отметить «Также удалить ИИ-модели»; иначе они остаются для следующей установки или портативной версии.

Где редактор хранит данные
--------------------------
%LOCALAPPDATA%\BoulderVideoEditor\ — настройки и список недавних проектов (config), ИИ-модели (models), файлы
восстановления (recovery), кэш (cache), журналы (logs). Проекты сохраняются туда, куда вы их сохраняете.
В папку программы редактор ничего не пишет.

FFmpeg
------
В папке ffmpeg\ — минимальная сборка FFmpeg для этого редактора (лицензия GNU GPL версии 2 или новее).
Её состав и лицензии: ffmpeg\THIRD-PARTY-NOTICES.txt; полный исходный код опубликован вместе с релизом
(aive-ffmpeg-minimal-*-sources.tar).

Журналы
-------
%LOCALAPPDATA%\BoulderVideoEditor\logs — при проблеме приложите файлы app-*.log, errors-*.log и ffmpeg-*.log.

Лицензии
--------
THIRD-PARTY-NOTICES.txt и папка licenses\ — сторонние компоненты программы; ffmpeg\THIRD-PARTY-NOTICES.txt — FFmpeg;
models-licenses\ — ИИ-модели. BUILD-INFO.txt — версия, коммит и состав сборки.
